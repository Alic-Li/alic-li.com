个人网站可以是一本实用的笔记：记录完成的作品、尚在探索的问题，以及过程中的收获。

这次初步构建从一个简单的想法出发：让内容清晰，让界面安静。

## 尽可能静态化

网站的大部分内容都是提前生成的 HTML。Astro 将交互式 React 组件限制在小范围内：外观设置、视觉实验和聊天实验场。

```ts
// 内容静态生成，只有 API 需要 Worker。
export const prerender = false;
```

这样的边界让网站易于部署，也让阅读体验不依赖 JavaScript。

## 两种语言，同一个空间

英文位于 `/`，简体中文位于 `/zh/`。切换语言时保留当前页面，不会因为浏览器语言自动跳转。

## 少量玻璃，更多清晰

半透明材质应当服务于明确的目的。在这里，它让导航与页面之间形成轻微的层次。更强的视觉效果仅作为装饰，并为不同浏览器与无障碍偏好提供简洁的降级方案。

## 接下来

基础已经搭好。项目、笔记与实验可以按照自己的节奏慢慢生长。
